# 🗺 Дорожная карта развития проекта (ROADMAP)

## 🎯 Стратегический вектор
* **Крипторынок (Binance):** Исследовательский полигон для калибровки математических гипотез, тестирования NLP-моделей и валидации фильтрации спекулятивного шума в режиме 24/7.
* **Российский фондовый рынок (Мосбиржа):** Целевой рынок для практического применения стратегий и извлечения прибыли за счет высокой доли эмоционального розничного капитала (80%+ физлиц), прямолинейных катализаторов (дивиденды, ставка ЦБ) и выраженных Telegram-пампов.

- [ ] **Параллельный дуэт воркеров (Groq + Google Gemini):**
  - Поднять в `docker-compose.yaml` независимые сервисы `llm-groq` (Qwen/Llama) и `llm-gemini` (`gemini-1.5-flash`).
  - Обойти минутные лимиты токенов (TPM) Groq за счет гигантского лимита Gemini Flash (1 000 000 TPM, 1 500 запросов/сутки бесплатно).

  - В `llm/analyzer.py` отправлять прямые запросы с `response_format={"type": "json_object"}` для облачных API без промежуточных сбоев метода `.parse()`.
  - Увеличить чистую скорость разбора очереди в 2 раза.

  - Мониторинг ключевых каналов:
    - Крупные агрегаторы новостей (РДВ, Сигналы РБК, MMI, MarketOverview).

## 🤖 ЭТАП 4. Торговый бот и монетизация стратегии
- [ ] **Telegram-бот оперативных сигналов (Полуавтомат):**
  - Бот для личных уведомлений о качественных сетапах в реальном времени.
  - Карточки сигналов двух типов:
    - 🟢 **Momentum:** покупка/продажа по твердому факту (`is_speculative = FALSE`, Win Rate ~73%).
    - 🔴 **Fade the Hype:** контртрендовый вход против эмоционального Telegram-пампа (`is_speculative = TRUE`, исторический возврат ~83.6%).
- [ ] **Интеграция с брокерским API:**
  - Подключение к **T-Bank (Tinkoff) Invest API v2** (gRPC / Python SDK `tinkoff-investments`) или **Finam Trade API**.

- [ ] **Жесткий риск-менеджмент:**

  - Ограничение плеча (максимум $1\text{x} \dots 2\text{x}$).
  - Временной выход из позиции (Time-stop через 2–4 часа при затухании импульса).
