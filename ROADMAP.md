# 🗺 Дорожная карта развития Sentix (ROADMAP)

## 🎯 Стратегический вектор
* **Крипторынок (Binance):** Исследовательский полигон для калибровки математических гипотез, тестирования NLP-моделей и валидации фильтрации спекулятивного шума в режиме 24/7.
* **Российский фондовый рынок (Мосбиржа):** Целевой рынок для практического применения стратегий и извлечения прибыли за счет высокой доли эмоционального розничного капитала (80%+ физлиц), прямолинейных катализаторов (дивиденды, ставка ЦБ) и выраженных Telegram-пампов.

## 📋 ЭТАП 1. Бесшовность и ускорение LLM-инференса (0 ₽ затрат)

  - Предотвратить дублирование обработки одних и тех же новостей параллельными репликами (Race Condition).
  - Внедрена система версионированных миграций `migrations/` и команда `make db-migrate`.
- [ ] **Параллельный дуэт воркеров (Groq + Google Gemini):**
  - Поднять в `docker-compose.yaml` независимые сервисы `llm-groq` (Qwen/Llama) и `llm-gemini` (`gemini-1.5-flash`).
  - Обойти минутные лимиты токенов (TPM) Groq за счет гигантского лимита Gemini Flash (1 000 000 TPM, 1 500 запросов/сутки бесплатно).
- [ ] **Скользящее окно рыночной памяти (Rolling Context Window):**
  - Внедрение компактного блока оперативного фона (100–150 токенов) в системный промпт перед текстом анализируемой статьи.
  - Легковесный SQL-запрос последних 3–5 обработанных событий из `raw_news` (извлечение сжатых векторов: `sentiment_score`, `impact_magnitude`, `transmission_channel`, `key_takeaways`).
  - Фильтрация ложных импульсов: если общий макро-фон рынка за последние 6 часов резко негативный, локальный бычий импульс отсекается как высокорисковая «бычья ловушка».
  - Понимание хронологии нарративов (динамическая цепочка: Слух $\to$ Опровержение $\to$ Официальное подтверждение).
- [ ] **Оптимизация прямого JSON-режима:**
  - В `llm/analyzer.py` отправлять прямые запросы с `response_format={"type": "json_object"}` для облачных API без промежуточных сбоев метода `.parse()`.
  - Увеличить чистую скорость разбора очереди в 2 раза.
- [ ] **Каскадная обработка новостей (Two-Tier Cascade Architecture):**
  - **Tier 1 (Легковесный локальный фильтр шума, 0 ₽, ~100–300 мс):**
    - Быстрый первичный классификатор на базе ультралегкой модели (`Qwen-2.5-3B` / `Llama-3.2-3B` локально через MLX/Ollama или эвристический rule-based / regex-фильтр).
    - Оценка новости по бинарному признаку: `is_market_moving: bool` (наличие реального катализатора, изменения предложения/спроса, регуляторного или макроэкономического события).
    - Автоматическое отсечение ~70% информационного шума (реклама щиткоинов, биржевые конкурсы, бытовой фиатный скам, повторы, общие IT-конференции) без траты ресурсов тяжелых моделей.
  - **Tier 2 (Тяжелый институциональный мозг):**
    - Отправка только оставшихся 20–30% значимых событий на глубокий анализ с цепочкой рассуждений (CoT) в `DeepSeek-R1` (локальный MLX 14B или облачный 671B / `Llama-3.3-70B`).
    - **Эффект:** снижает затраты на облачные API в 4–5 раз, ускоряет разгребание очереди и экономит до 80% времени инференса.

## 📡 ЭТАП 2. Потоковый сбор данных рынка РФ (Факты + Telegram)
- [x] **Разделение рынков в архитектуре и БД (Миграция 004):**

  - Все исторические крипто-новости помечены как `'crypto'`, новые потоки размечаются как `'moex'`.
- [ ] **Первоисточники твердых фактов (Hard Catalysts):**
  - **Центр раскрытия корпоративной информации ([e-disclosure.ru](https://e-disclosure.ru) / Интерфакс):** парсер существенных фактов (решения СД по дивидендам, отчетность, оферты, созывы ВОСА).
  - **Пресс-релизы Банка России (`cbr.ru/rss`):** решения по ключевой ставке, макропруденциальные надбавки, резюме обсуждения ставки.
  - **Деловые СМИ в `go-collector`:** подключение RSS-лент РБК Котировки, Ведомостей, Коммерсанта и Интерфакса.
- [ ] **Отдельный микросервис `tg-collector` (MTProto Push-Listener на Go):**
  - **Стек и технологии:** чистый Go (Golang) на базе высокопроизводительной библиотеки **[`gotd/td`](https://github.com/gotd/td)** (полная реализация MTProto без CGO).
  - **Архитектурная чистота:** весь сбор данных (`go-collector` для RSS + `tg-collector` для Telegram) пишется на Go в рамках единого Ingestion-слоя.
  - **Переиспользование кода:** 100% переиспользование проверенных пакетов `database.Repository`, `insert_news.sql` и структур `model.NewsItem` с автоматической маркировкой `Market: "moex"`.
  - **Ультралегкий контейнер:** Alpine-образ весом **~20 МБ** с минимальным потреблением ресурсов (**всего 15–25 МБ RAM**) и молниеносной задержкой обработки сообщений (**1–3 мс**).
  - **Модель реального времени:** постоянный TCP-стрим по протоколу MTProto через диспетчер обновлений `dispatcher.OnNewChannelMessage(...)`.
  - **Список мониторинга каналов:**
    - Официальные: `@cbrfinancial` (Банк России).
    - Деловые СМИ: `@rbc_news`, `@prime1`, `@interfaxonline`.
    - Брокерские ленты: `@bcs_express`, `@tinkoff_invest_official`.
    - Трейдерские агрегаторы: `@markettwits` / `@marketoverview`, `@smartlabnews`, `@mmi_channel`.
  - **Контейнеризация:** выделенный сервис `sentix-tg-collector-1` в `docker-compose.yaml` с монтированием тома для персистентной сессии (`./tg-collector/sessions:/app/sessions`).
  - **Изоляция сбоев:** автоматический реконнект, обработка `FloodWait` и сохранение сессии без перезапуска и влияния на RSS-пайплайн.

    - Биржевая комиссия в 5–8 раз ниже спота (`~0.02%` на круг).
    - Капиталоэффективность: остаток средств (~75–80% депозита) работает в фонде ликвидности `LQDT` под ставку ЦБ.
- [ ] **Интеграция с брокерским API:**
  - Подключение к **T-Bank (Tinkoff) Invest API v2** (gRPC / Python SDK `tinkoff-investments`) или **Finam Trade API**.

- [ ] **Жесткий институциональный риск-менеджмент:**

  - **Автоматический выключатель (Daily Circuit Breaker):** принудительный сон системы на остаток дня при получении **2 стоп-лоссов подряд** (`-3.6%` от депозита) для защиты от аномальных сломов рыночного режима.
  - Временной выход из позиции (Time-stop через 2–4 часа при затухании импульса).
- [ ] **Монетизация в формате B2C/B2B SaaS (AI-аналитический ассистент):**
